# A股周/月频规则选股与高低点标注系统（第一版）

第一版**刻意不含任何机器学习**。目标是先把地基立住：数据口径对不对、标签定得合不合理、
回测框架有没有泄漏未来信息。地基没验证过之前上模型，只会把错误放大得更快、更难查。

## 快速开始

```bash
# 1. 建环境
python -m venv .venv && .venv/Scripts/pip install pandas numpy requests

# 2. 先用小股票池跑通（约 1 分钟）
python run_pipeline.py --universe 40 --pages 1

# 3. 确认流程无误后扩大范围
python run_pipeline.py --universe 150 --pages 3

# 4. 单模块自测
python datasource.py     # 只验证数据接口
python labeling.py       # 只验证三重障碍标注
```

常用参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--period` | week | week / month |
| `--bars` | 800 | 每只股票拉多少根 K 线（腾讯周线上限约 800，再大反而被截断） |
| `--universe` | 150 | 取成交额前 N 只 |
| `--top-n` | 20 | 每期持仓数量 |
| `--max-hold` | 8 | 三重障碍的时间壁垒（持有多少期） |
| `--upper` / `--lower` | 1.0 / 0.8 | 壁垒宽度系数，越大越难触发 |
| `--rebalance` | 4 | 每 N 期调仓一次 |
| `--refresh` | 关 | 忽略本地缓存重新拉取 |
| `--no-pit` | 关 | 关闭按历史时点选池，用于对比幸存者偏差的影响 |
| `--start` | 无 | 样本起始日期，**做 A/B 对比时必须两边对齐** |

## 三层核心设计

### 标注层：为什么必须用三重障碍

最常见的错误是用"事后 N 天最高点"当标签。那个高点只有站在未来才知道，回测胜率会高得离谱，
实盘直接归零。三重障碍的做法是：从每个候选点同时设上轨、下轨、时间壁垒，
先碰到哪条取哪个标签，全程只用当前时刻已知的信息。

三个必须记住的取舍：

1. **用超额收益而非绝对收益**。全市场选股时大盘 beta 会淹没个股 alpha。
   基准默认用**横截面中位数**（不是等权均值——均值会被少数暴涨股拉高，
   导致绝大多数股票被判为"跑输"，标签严重偏向 -1）。
2. **同一根 K 线内上下轨都被击穿时无法判定先后顺序**（周月线没有日内信息）。
   默认 `skip` 丢弃该样本，丢弃比例会在报告里显式打印。
3. **壁垒宽度按持有期缩放**：`壁垒 = 系数 × 单期波动率 × sqrt(持有期数)`。
   直接用单期波动率会让 8 周的壁垒窄到失真。

调参指引（跑完看"标注层"那段输出）：

- 震荡样本（标签 0）> 60% → 壁垒偏宽，调小 `--upper` / `--lower`
- 震荡样本 < 10% → 壁垒偏窄，标签退化成方向判断，调大系数
- 正负样本相差超过 50% → 检查基准是否合适

### 验证层：及格线

| 指标 | 及格线 | 说明 |
|---|---|---|
| IC 均值 | > 0.03 | 低于此值预测力不足 |
| IR | > 0.5 | IR = IC均值/IC标准差，衡量稳定性 |
| IC 正率 | > 55% | 低于 50% 视为不可用 |
| IC 均值 | < 0.1 | **高得反常要警惕前向偏差，而不是庆祝** |
| 分层单调性 | > 60% | 好因子要组间单调，不能只有头尾好 |
| 扣成本年化 | > 0 | 成本含双边佣金、滑点、卖出印花税 |

两个额外提醒：

- 标签期重叠会夸大显著性，代码里已按 `有效样本数 = 期数 / max_hold` 下调 t 统计量
- 回测拟合度 80-90% 才合理，超过 95% 基本是过拟合；实盘预期按回测打 **5-7 折**

### 市场状态：为什么先做这个而不是先做选股

周月频选股贡献的是 alpha，但账户生死主要由 beta 决定。同样一套选股逻辑，
趋势市能赚 30%，震荡市会因为反复被打脸亏掉 15%。先用硬规则把市场分成
趋势 / 震荡 / 末端 / 下跌，再让状态决定仓位上限（1.0 / 0.5 / 0.3 / 0.2），
比任何复杂模型都更能改善实盘体验。

`regime_report()` 会输出各状态下的后续收益——如果"趋势"和"下跌"没有明显差别，
说明这套规则没捕捉到有效信息，应该直接弃用而不是硬套。

## 实测结果（诚实记录）

配置：周线、成交额前 150 只（有效 148 只）、756 根 K 线（**2011-12 ~ 2026-09**）、
按历史时点动态选池、持有 8 期、上轨 1.0σ√8、下轨 0.8σ√8。

**机制自检通过**：未来收益 vs 自身的 IC = 1.0000，滞后 8 期后降到 -0.033。
说明面板对齐与 IC 算法正常——下面的结论是"因子没用"，不是"框架坏了"。

### 结论一：8 个通用价量因子在 A 股周线上没有可用 alpha

| 因子 | IC均值 | IR | IC正率 | t统计量 |
|---|---|---|---|---|
| rev_4（反转） | +0.034 | +0.16 | 54.2% | +1.56 |
| low_vol_12 | +0.008 | +0.04 | 51.1% | +0.37 |
| low_amp_8 | +0.006 | +0.02 | 49.5% | +0.23 |
| trend_slope | -0.016 | -0.07 | 50.6% | -0.67 |
| mom_12_1 | -0.019 | -0.09 | 47.9% | -0.85 |
| pos_52 | -0.026 | -0.12 | 45.2% | -1.11 |
| amount_trend | -0.024 | -0.13 | 45.2% | -1.27 |
| trend_dev | -0.030 | -0.13 | 44.0% | -1.25 |
| **综合得分** | **-0.008** | **-0.04** | **49.3%** | **-0.41** |

全部未达 IC>0.03 且 IR>0.5 的及格线，没有任何一个因子的 t 统计量超过 2。
分层单调性 50%（等同抛硬币）。

### 结论二：方向是"反转优于动量"，但样本外兑现不了

5 个动量/趋势类因子**全部为负**，唯一的正值是反转因子 rev_4，
且分年度看 rev_4 在 11/15 年为正、mom_12_1 在 11/15 年为负。
这个方向和"下跌状态后续收益高于趋势状态"的发现互相印证——
**A 股周线尺度上均值回归强于动量**，符合散户占比高、换手快的市场结构。

但方向一致 ≠ 能赚钱。用 walk-forward 严格检验（训练窗定方向、测试窗验证、
中间 8 期 embargo 隔离）：

| 指标 | 结果 | 及格线 |
|---|---|---|
| 样本外 IC 均值 | **+0.0138** | > 0.03 |
| 样本外 IC 为正的窗口 | **11/22** | > 55% |
| 跨窗 IR | **0.156** | > 0.5 |

**等于抛硬币。** 而且调高方向置信度门槛（只保留训练窗 |IC| > 0.02/0.03/0.05 的因子）
也没有改善，样本外 IC 始终在 0.013 附近：

| 门槛 | 平均入选因子数 | 样本外IC均值 | IC为正的窗口 | 跨窗IR |
|---|---|---|---|---|
| 0.00 | 8.0 | 0.0138 | 11/22 | 0.156 |
| 0.01 | 6.4 | 0.0146 | 11/22 | 0.161 |
| 0.02 | 5.1 | 0.0132 | 13/22 | 0.151 |
| 0.03 | 4.5 | 0.0133 | 12/19 | 0.132 |
| 0.05 | 3.3 | -0.0050 | 7/14 | -0.056 |

淘汰掉弱因子也不见效，说明问题不在"因子里混了几个坏的"，
而是**这类价量因子整体就在噪声水平**。继续在这 8 个因子上调权重属于浪费时间。

**这是本项目最有价值的产出**：不是说"我调出了一个好策略"，
而是用严格的方法确认"这条路不通"，并定位到原因（因子类型不对，不是权重不对）。

### 结论三：幸存者偏差几乎全在基准上，把收益夸大了近一倍

等区间（同 735 期，2011-12 ~ 2026-09）A/B 对比：

| 指标 | 修复前（幸存者偏差） | 修复后（按历史时点选池） | 差异 |
|---|---|---|---|
| **等权基准年化** | **100.5%** | **50.8%** | **-49.7pp** |
| 基准最大回撤 | -40.5% | -53.9% | 低估 13.4pp |
| 组合年化 | 32.1% | 31.4% | -0.7pp |
| 因子 IC | 基本一致 | 基本一致 | — |

用"今天还活着且成交活跃"的股票回测，等于预先剔除了后来跌到无人问津的股票，
池子整体表现自然虚高。**组合本身受影响很小**（只选 top 20），
所以偏差全部体现在"组合 vs 基准"的相对评价上：

- 修复前：组合 32.1% vs 基准 100.5% → 看起来跑输 **68 个百分点**
- 修复后：组合 31.4% vs 基准 50.8% → 实际跑输 **19 个百分点**

**之前那个"选股严重拖后腿"的绝望结论，有 50 个百分点是幸存者偏差造出来的假象。**

### 结论四：规则引擎再次被证伪（这是好事）

"下跌"状态后续 4 期平均收益 +0.71%，"趋势"状态 +0.65%，两者几乎没有差别。
按状态调节仓位把年化从 31.4% 降到 22.2%，只是白白损失收益。

规则引擎的价值恰恰在这里——**它能被快速证伪**。一个黑箱模型会让你
纠结好几个月才发现方向反了，而这里跑一次就看得清清楚楚。

### 结论五：新信息源——大宗交易是唯一通过 walk-forward 的因子，基本面在大市值池失效

本轮补齐了另类数据层（大宗交易，150/150 全覆盖）与基本面层（财务，150/150 全覆盖），
并用 walk-forward 严格验证（训练窗定方向、测试窗验证、embargo 隔离）。

**大宗交易（5 因子，覆盖率中位 34%）——唯一达标的新因子：**

| 对象 | 样本外IC | 正窗口 | 跨窗IR | 分年度 | 判定 |
|---|---|---|---|---|---|
| **`block_freq_inv`（大宗频率反向）** | +0.044 | 7/8 | +0.66 | 4/5 正值（近年增强） | ✅ 达标 |
| 大宗组等权 | +0.010 | 5/8 | +0.30 | — | 弱正 |

- 方向与"大宗=负面信号"的定位完全一致：某只股票近期大宗交易越频繁，后续相对收益越差，
  与"折价是常态、频繁大宗=后续更差"的实证发现吻合。
- 已达 IC>0.03、IR>0.5 的及格线，**已并入综合得分**（`config.use_block_factor=True`）。
- `risk_flag`（深度折价 / 大宗占成交比过高）累计触发 133 只、周命中率 5.8%，
  作为选股池剔除项（`score.mask(risk)`）接入主流程。

**基本面（15 因子，覆盖率中位 45%）——大市值池无效：**

| 对象 | 样本外IC | 跨窗IR | 判定 |
|---|---|---|---|
| 基本面组等权 | -0.003 | -0.03 | ❌ 大市值池无效 |
| `ep_ttm`（单因子最好，全样本 IC +0.040） | — | — | 2025-26 转弱，不稳 |

- 印证"基本面 alpha 在小市值更显著"的共识——当前池子是成交额前 150 只（大盘股为主），
  估值/盈利的横截面区分度被压平。
- 因此基本面**仅作 IC 报告、不并入得分**（`config.use_fundamental=False`）。

**并入主流程后的回测对比**（三变体 × 两调节，top20，持有 8 期，不调节一栏）：

| 变体 | 年化收益 | 夏普 | 最大回撤 | Calmar |
|---|---|---|---|---|
| 量价基线｜不调节 | 31.4% | 0.97 | -60.6% | 0.52 |
| 量价+大宗｜不调节 | 33.0% | 1.01 | -60.6% | 0.55 |
| 量价+大宗+风控｜不调节 | 33.1% | 1.02 | -60.6% | 0.55 |
| 等权基准 | 50.8% | 1.31 | -53.9% | 0.94 |

- 并入 `block_freq_inv` 后扩展综合得分**轻微优于**量价基线（夏普 1.02 vs 0.97），幅度很小；
  风控过滤在年化/夏普上几乎无差异（标的已被 top20 截断，被剔除的少数标的本就难进前排）。
- 关键结论：新因子**没有把组合从"跑输基准"变成"跑赢"**，但验证了
  "大宗交易作为负面信号"的假设可纳入框架，且挖掘方向已清晰——
  **另类数据 > 价量 > 基本面（在大市值池）**，下一版应继续挖另类数据而非回头调价量。

## 已修的数据层隐患（都是"不报错、静默给错结果"型）

这几条都是本项目实际踩过的坑，改代码前务必先读：

1. **`000xxx` 号段个股与指数重号**。`sz000001` 是平安银行，`sh000001` 是上证指数；
   `sz000938` 是紫光股份（约 25 元），`sh000938` 是某个中证指数（约 2300 点）。
   早期版本按前缀把 000xxx 一律判成指数，导致所有深市主板股票取回的是指数数据，
   价格差百倍，且**全程不报错**——面板照样拼出来、IC 照样算出来。
   现在改为 `is_index` 显式声明，并加了跨源校验兜底。
2. **腾讯 K 线 `bars` 超过 800 会被静默截断**。传 1000/1500/2000 都只返回 641 根
   （≈2014 年），比传 800 拿到的 801 根（≈2011 年）还少。不要指望加大参数。
3. **前复权价不能用于绝对价格过滤**。分红送转会系统性压低历史价格，
   实测 2013 年池内股票前复权价中位数仅 3.83 元，73 只里 22 只低于 2 元——
   全是大盘蓝筹，不是仙股。用 2 元阈值会凭空砍掉三分之一样本。
   仙股由成交额条件拦截即可，它不受复权方式影响。
4. **早期期次的截面样本太小**。池子里只有三五只股票时算秩相关得到的是纯噪声，
   却会混进 IC 均值。代码里按 `pit_min_names` 自动裁掉这些期次。

## 已知限制（下一版要解决的）

1. **幸存者偏差只消除了一部分**。`universe.py` 消除的是流动性层面的选择偏差；
   数据源（东财当前股票列表）里没有已退市股票，它们从头到尾都不会出现。
   真正的无偏池需要含退市股的历史全样本，免费公开接口拿不到。
2. **基本面因子在大市值池被证伪**：财务数据已接入（150/150 全覆盖），
   walk-forward 验证 IC≈0 甚至为负，**仅作 IC 报告、不并入得分**。
   估值/盈利 alpha 在小市值更显著，而当前池子是成交额前 150 只（大盘股为主），
   横截面区分度被压平。另类数据目前只有大宗交易一种，覆盖率中位仅 34%，
   覆盖面是下一版要补的短板。
3. **样本量是硬约束**：周频 14 年约 730 个截面，但标签重叠 8 期，
   有效独立样本只有约 90 个。做模型时参数量必须压到十几个以内。
4. **周月线无法判断 K 线内先后顺序**，只能用 `skip` / `pessimistic` 兜底。
5. **未做涨跌停与停牌处理**：涨停无法买入、停牌无法卖出，会高估实盘可执行性。

## 下一步路线

优先级已根据实测结果调整：

1. **补另类数据，而非回头挖基本面**。基本面在大市值池已被 walk-forward 证伪，
   而大宗交易的 `block_freq_inv` 是本轮唯一通过及格线的新因子。
   下一版应扩展另类数据覆盖面（融资融券、北向资金、龙虎榜、公告/新闻情绪等），
   把单一种类 34% 的覆盖率提上去，再验证"另类数据 > 价量 > 基本面"的方向是否成立。
2. **扩大股票池与样本长度**。当前只有成交额前 150 只（大盘股为主），
   而反转效应在小盘股上通常更强。
3. **再谈模型**。在上述两项稳定之前，上任何模型都只是把噪音拟合得更好看。
   届时也只做"学习规则权重"（参数量十几个），不做端到端预测。

> 再次强调：本系统用于研究方法论与验证框架，**不构成任何投资建议**。
